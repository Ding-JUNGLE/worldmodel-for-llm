# External Memory Scripts

These scripts are lightweight wrappers and helpers for reproducing the inference-time external-memory workflow.

Actual available script names in this repo:
- extract_keyframes.py
- build_memory_bank.py
- retrieve_memory.py
- rerank_candidates.py
- build_landmark_memory.py
- evaluate_contact_sheet.py

Legacy names in the source experiment folder may differ (for example `run_baseline.sh`, `run_candidates.sh`, `memory_utils.py`).

The project does **not** modify Matrix-Game-2 source. It only uses external scripts.
