# 演讲者讲稿草稿

## 第1页：项目动机
在长视频生成里，冻结模型常常在关键时刻忘掉前面出现过的对象或标识，导致画面一致性变差。

## 第2页：基线模型
我们只使用 Matrix-Game-2 的固定推理能力，不改模型参数、不改 Transformer 结构。

## 第3页：记忆模块位置
记忆模块并非插在模型内部，而是外置在推理流程外。也就是“生成后重排”而非“网络内注入”。

## 第4页：记忆生命周期
先在第一段视频中写入记忆，再检索相似历史，再按分数重排候选。

## 第5页：数据结构
每条记忆包含关键帧、目标区域裁剪、框、特征向量，最后以 JSONL 存储，便于重放和审计。

## 第6页：实验设计
我们对比了 no_memory、uniform_memory、recent_only、random_memory、wrong_scene、auto/approved memory 等条件。

## 第7页：主对比
展示 seed1 的无记忆结果和 seed8 的 road-sign 记忆结果。

## 第8页：结果
主结论是：approved_roadsign_memory 的 selected seed 与 baseline 不同，说明外置 rerank 能影响输出选择。

## 第9页：解释
这不是“让模型会记住”，而是通过外部记忆信号改变备选轨迹选择，提升对象保持的可能性。

## 第10页：局限
只改了推理后处理路径；没有内嵌到模型内部；现阶段为定性比较，不是完备指标体系。

## 第11页：未来工作
更细粒度地按时间更新 memory、加入 3D 记忆、学习式 rerank、更多场景对比。

## 第12页：结论
在不改模型的前提下，外部记忆控制是一个可复制、成本低、工程可落地的改进方式。
