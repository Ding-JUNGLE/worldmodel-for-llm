# Demo Videos

This folder contains compressed demo videos for the final assignment.

## Videos

- `no_memory_seed1.mp4`
- `with_roadsign_memory_seed8.mp4`
- `no_memory_vs_roadsign_memory_side_by_side.mp4`

## Meaning

No-memory uses the default baseline selected candidate: seed1.

With-memory uses the approved road-sign memory selected candidate: seed8.

The side-by-side video is the recommended demo for the presentation.

Videos are compressed for GitHub. Full-resolution originals remain in the local Matrix-Game-2 outputs directory.
